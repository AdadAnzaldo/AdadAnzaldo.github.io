Vehicle Services Digital PlatformPlataforma Digital de Servicios Vehiculares

This project involved the development of a complete digital platform for a vehicle registration services company specialized in procedures such as vehicle registration, deregistration, ownership transfers, plate replacements, and compliance management. Este proyecto incluyó el desarrollo de una plataforma digital completa para una empresa de servicios de registro vehicular especializada en trámites como alta, baja, transferencias de propiedad, reemplazo de placas y gestión de cumplimiento.
Beyond creating a modern corporate website, the solution provides real-time tracking capabilities that allow both individual customers and companies managing large vehicle fleets to monitor the status of their procedures online. Through a secure integration with a centralized database, clients can instantly access updated information using their RFC, significantly improving transparency and customer experience. Más allá de crear un sitio corporativo moderno, la solución ofrece capacidades de seguimiento en tiempo real que permiten tanto a clientes individuales como a empresas con grandes flotas monitorear el estado de sus trámites en línea. Mediante una integración segura con una base de datos centralizada, los clientes pueden acceder instantáneamente a información actualizada usando su RFC, mejorando significativamente la transparencia y la experiencia del cliente.
To streamline internal operations, a custom desktop application was also developed using Python and Flet. By simply uploading an Excel file, company staff can automatically synchronize and update records stored in Supabase, eliminating manual data entry and ensuring accurate, real-time information across the platform. Para agilizar las operaciones internas, también se desarrolló una aplicación de escritorio personalizada con Python y Flet. Solo con subir un archivo Excel, el personal de la empresa puede sincronizar y actualizar automáticamente los registros almacenados en Supabase, eliminando la entrada manual de datos y garantizando información precisa y en tiempo real en toda la plataforma.

Technology & FunctionalityTecnología y Funcionalidad

This project was developed as a comprehensive digital platform for a vehicle registration services company. The solution combines a public-facing website, a centralized cloud database, and an internal desktop application to streamline both customer interactions and operational workflows. Este proyecto se desarrolló como una plataforma digital integral para una empresa de servicios de registro vehicular. La solución combina un sitio web orientado al público, una base de datos en la nube centralizada y una aplicación de escritorio interna para optimizar tanto las interacciones con los clientes como los flujos operativos.

The web platform allows customers to access information about services such as vehicle registration, deregistration, ownership transfers, plate replacements, and compliance-related procedures. In addition to providing online visibility for the business, the platform offers a real-time tracking system that enables clients to check the status of their procedures directly through the website. La plataforma web permite a los clientes acceder a información sobre servicios como alta, baja, transferencias de propiedad, reemplazo de placas y trámites relacionados con cumplimiento. Además de brindar visibilidad en línea para el negocio, la plataforma ofrece un sistema de seguimiento en tiempo real que permite a los clientes verificar el estado de sus trámites directamente desde la web.

To support organizations managing large vehicle fleets, a dedicated consultation module was implemented. Customers can search and retrieve information associated with their RFC, allowing fleet managers to monitor multiple ongoing procedures efficiently without requiring manual assistance from company personnel. Para apoyar a las organizaciones que gestionan grandes flotas vehiculares, se implementó un módulo de consulta dedicado. Los clientes pueden buscar y recuperar información asociada a su RFC, lo que permite a los administradores de flotas monitorear múltiples trámites en curso de manera eficiente sin requerir asistencia manual del personal de la empresa.

On the operational side, a custom desktop application was developed using Python and Flet. The application allows employees to upload Excel spreadsheets containing updated procedure information. Once uploaded, the data is automatically validated, processed, and synchronized with the Supabase database, ensuring that customers always have access to accurate and up-to-date information. En el lado operativo, se desarrolló una aplicación de escritorio personalizada con Python y Flet. La aplicación permite a los empleados subir hojas de cálculo en Excel con información actualizada de trámites. Una vez cargados, los datos se validan, procesan y sincronizan automáticamente con la base de datos de Supabase, garantizando que los clientes siempre tengan acceso a información precisa y actualizada.

By integrating web technologies, cloud databases, SQL, and process automation, the platform significantly improves customer transparency, reduces administrative workload, and provides a scalable solution capable of supporting both individual clients and enterprise fleet operators. Al integrar tecnologías web, bases de datos en la nube, SQL y automatización de procesos, la plataforma mejora significativamente la transparencia para los clientes, reduce la carga administrativa y ofrece una solución escalable capaz de dar soporte tanto a clientes individuales como a operadores de flotas empresariales.

ArchitectureArquitectura

A decoupled client-server architecture designed for high availability, secure data queries, and automated internal operations. Una arquitectura cliente-servidor desacoplada diseñada para alta disponibilidad, consultas seguras de datos y operaciones internas automatizadas.

Conceptual illustration of the architecture project on three principal elements. Ilustración conceptual de la arquitectura del proyecto en tres elementos principales.

Web Frontend (Hostinger):Frontend Web (Hostinger): Built with native web technologies (HTML5, CSS3, Vanilla JS). It implements a frictionless Dual-Factor Query mechanism—requiring both the client's RFC and Vehicle Circulation Card—to securely expose real-time tracking data without traditional user authentication.Construido con tecnologías web nativas (HTML5, CSS3, Vanilla JS). Implementa un mecanismo de consulta Dual-Factor sin fricción que requiere tanto el RFC del cliente como la tarjeta de circulación del vehículo para exponer de forma segura datos de seguimiento en tiempo real sin autenticación tradicional.

Database & Backend (Supabase):Base de Datos y Backend (Supabase): Acts as the system's Single Source of Truth utilizing PostgreSQL. All clients communicate via native REST APIs, eliminating middleware latency and streamlining CRUD operations.Actúa como la fuente única de verdad del sistema utilizando PostgreSQL. Todos los clientes se comunican a través de REST APIs nativas, eliminando la latencia del middleware y simplificando las operaciones CRUD.

Operational Desktop App (Python & Flet):Aplicación de Escritorio Operativa (Python & Flet): A custom internal tool featuring an automated ETL pipeline. It parses administrative files locally (pandas for .csv, openpyxl for .xlsx) to validate data integrity before executing batch synchronizations to the cloud database.Una herramienta interna personalizada con un pipeline ETL automatizado. Analiza archivos administrativos localmente (pandas para .csv, openpyxl para .xlsx) para validar la integridad de los datos antes de ejecutar sincronizaciones por lotes con la base de datos en la nube.
